# 업비트(Upbit) 프로젝트 디자인 & 기획 가이드라인

> 본 문서는 업비트 앱 스크린샷 55장 분석을 기반으로 역추출한 디자인 시스템 및 UX 패턴 가이드라인입니다.
> 신규 기능 기획 및 프로토타입 제작 시 이 문서를 기준으로 삼습니다.

## 1. 프로젝트 컨텍스트

- **서비스명**: 업비트 (Upbit) — 대한민국 최대 가상자산 거래소
- **운영사**: 두나무(Dunamu)
- **플랫폼**: iOS / Android 네이티브 앱
- **담당자 포지션**: UI/UX 디자이너 → 서비스 기획(Product Planning) 역량 확장 중
- **목표**: 글로벌 톱티어(Binance, OKX) 수준의 고도화된 기능을 한국 시장에 맞게 로컬라이징하는 '풀스택 기획자'로 성장
- **주요 툴**: Figma, Claude, Replit
- **디자인 시스템**: 다크모드 / 라이트모드 모두 지원하는 Figma 라이브러리 구축 완료

| 경고 배너 BG | 인라인 경고 배경 | `#FFEBEE` |
| 경고 배너 텍스트 | 인라인 경고 텍스트 | `#D32F2F` |

> 글로벌 Green/Red 방식 절대 사용 금지

### 2-2. 타이포그래피

> ⚠️ **절대 규칙**: **모든 환경(앱/웹/프로토타입/Figma)에서 Pretendard를 무조건 사용한다.**
> 시스템 폰트(SF Pro, Roboto 등) 및 기타 폰트 사용 금지. 폴백 체인에도 시스템 폰트 포함 불가.
> CDN: `https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.css`
> CSS 적용: `font-family: 'Pretendard', sans-serif;` — 폴백은 sans-serif 제네릭만 허용

- **행간 (line-height)**: 1.4 ~ 1.6 (여유 있게 유지)

| 레벨 | 용도 예시 | 크기 | 굵기 |
|------|-----------|------|------|
| H1 | 페이지 타이틀, 코인빌리기 헤드카피 | 22~24px | Bold 700 |
| H2 | 섹션 헤더 (보유자산 포트폴리오 등) | 16~18px | SemiBold 600 |
| Body1 | 코인명, 주요 수치 | 14~15px | Regular~Medium |
| Body2 | 설명 텍스트, 서브 정보 | 12~13px | Regular 400 |
| Caption | 타임스탬프, 단위 표기 | 11~12px | Regular, 회색 |
| 현재가 강조 | 종목 상세 현재가 숫자 | 24~28px | Bold (특별 처리) |

### 2-3. 컴포넌트 스펙

#### Border-radius
| 컴포넌트 | 값 |
|----------|-----|
| 풀와이드 메인 버튼 | 8px |
| 소형 버튼 (신청/모으기 등) | 6px |
| 카드 컴포넌트 | 12px |
| 정보 박스 (내부 배경 영역) | 8px |
| 입력창 (Input Field) | 6~8px |

#### Shadow
- **기본 철학**: Flat 디자인 기조 — 전반적으로 그림자 미사용
- 모달/팝업: 딤(Dim) 오버레이 + 흰 카드
- 드롭다운 메뉴: 미세한 box-shadow만 적용

#### 아이콘
- 기본 스타일: **Outlined (선형)**
- 활성 상태: **Filled (면형)** + Primary Blue 컬러
- Stroke width: 1.5~2px
- 탭바 아이콘: 비활성 Outlined 흰색 → 활성 Filled 흰색 + 블루 강조
- 경고 아이콘: 빨간 원형 배경 + 흰색 `!` (Filled)

## 3. 내비게이션 & IA 구조

### 3-1. GNB (Global Navigation Bar)

```
[Bottom Tab Bar — 5탭]
거래소 | 코인정보 | 투자내역 | 입출금 | 더보기
```

- 스타일: 다크 네이비 배경 + 흰색 아이콘 & 텍스트
- 활성 탭: 아이콘 Filled 전환 + 텍스트 강조

### 3-2. 화면 뎁스 구조

```
L1: Bottom Tab Bar (GNB)
 └── L2: Sub-tab (수평 탭)
      └── L3: 상세 화면
           └── Overlay: 모달 / 바텀시트
```

- 뒤로가기: 좌상단 `<` chevron 일관 적용
- 주요 Sub-tab 구성:
  - 거래소 종목 상세: 주문 / 호가 / 차트 / 시세 / 정보
  - 투자내역: 보유자산 / 투자손익 / 거래내역 / 미체결 / 자동주문
  - 코인정보: 코인동향 / 코인뉴스
  - 알림설정: 일반 / 시세
  - 종목 정보 탭: 주요 정보 / 마켓 인사이트

## 4. 정보 나열 방식 & 데이터 밀도

| 패턴 | 적용 화면 | 밀도 |
|------|-----------|------|
| 리스트형 | 거래소 코인 목록, 체결내역, 알림, 공지사항 | 중간~고밀도 |
| 카드형 | 보유자산 포트폴리오, 스테이킹, 코인모으기 | 저밀도 (여백 넉넉) |
| 혼합형 | 코인정보 탭, 입출금 화면 | 상단 카드 + 하단 리스트 |

**정보 노출 철학**
- 숫자/데이터 중심 설계
- 불필요한 장식 요소 최소화
- 일러스트는 교육성 랜딩/온보딩 화면에만 제한 사용

## 5. 버튼 배치 규칙

| 패턴 | 적용 상황 | 예시 |
|------|-----------|------|
| 풀와이드 하단 고정 | 단일 주요 액션 | KRW 입금신청, PIN 다음 |
| 좌우 분리 2버튼 하단 | 2개 액션 (보조/주요) | 초기화/매수, 취소/확인 |
| 인라인 우측 소형 버튼 | 리스트 내 즉시 액션 | 주문, 모으기, 신청 |
| 상단 우측 텍스트 버튼 | 부가 정보 링크 | 알아보기 |
| 플로팅 Pill 버튼 | 교육성 랜딩 화면 한정 | 빌리고 싶은 코인 선택 |

> **2버튼 규칙**: 좌측 = 보조(회색), 우측 = 주요(블루 or 레드)

## 7. 피드백 패턴

### 성공/완료
- 체결 완료: **팝업(모달)** 형태로 안내
- 입출금 완료: 내역 리스트에 상태 텍스트 표시 ("입금 완료" — 빨간 컬러)

### 에러/경고
- **전면 모달**: 보이스피싱 경고, 미신고 거래소 안내 등 중요 경고
- **인라인 배너**: `#FFEBEE` 배경 + `#D32F2F` 텍스트 + `!` 아이콘
- 경고 모달 버튼: 좌 "하루 동안 보지않기" / 우 "확인"

### 빈 상태 (Empty State)
- 흰 종이 문서 아이콘 + 안내 텍스트 (일관된 패턴)
- 선택적으로 CTA 버튼 추가 ("모으기 시작하기 >")

### 로딩 상태
| 방식 | 적용 화면 |
|------|-----------|
| 스켈레톤 UI | 정보 탭 콘텐츠 로딩 |
| 스피너 | 스플래시 초기 로딩 |
| 도트 애니메이션 (• • •) | 입금주소 발급 중 |

> ⚠️ 현재 로딩 패턴이 화면마다 혼용됨 — 신규 개발 시 통일 필요

## 8. 한국 시장 특화 규칙

### 절대 준수 사항
- 상승=빨강 / 하락=파랑 (Green/Red 방식 금지)
- 가격 표기: 쉼표 구분 원화 (예: `102,000,000 KRW`)
- 보이스피싱 / 금융 사기 관련 안내는 입출금 플로우에 필수 포함

### 한국 거래소 고유 개념
- **체결강도**: 매수세 비율 지표 (바이낸스에 없는 개념)
- **Taker 순매수**: 마켓 인사이트 탭 내 독자 데이터
- **사용자 등급제**: 원화 입출금 가능 여부에 따른 등급 표시
- **예약주문**: 설정 가격 도달 시 자동 실행되는 주문 유형
- **코인모으기**: DCA(Dollar Cost Averaging) 자동 매수 기능
- **코인빌리기**: 담보 기반 공매도 (Short Selling) 기능
