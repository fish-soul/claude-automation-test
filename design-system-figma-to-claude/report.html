발견된 이슈
이슈 1. 기간 선택 시 날짜 사이 흰 배경이 끊김
17~21일 선택 시 19·20일 주변에 흰 배경이 이어지지 않고 간격이 생김. 피그마 원본의 range 연결 레이어 구조를 정확히 파악하지 못한 것이 원인.
→ 방법 5에서 MCP 코드 분석으로 정확한 수식 확인 후 해결
이슈 2. 연도/월 피커가 처음엔 다른 형태로 구현됨
가이드에 플로팅 드롭다운 예시가 있었지만 Claude가 이를 제대로 인식하지 못하고, 달력 전체가 연도 선택 버튼으로 교체되는 방식으로 구현했다. 피커 컴포넌트 링크를 추가로 전달한 후에야 올바르게 수정됨.
→ 교훈: 버튼과 그 버튼이 여는 팝업이 별도 컴포넌트라면 두 링크를 모두 챙겨줄 것
