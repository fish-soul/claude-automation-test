# Native UX Writing - AI 시스템 가이드

## 프로젝트 개요
이 프로젝트는 Native 앱(iOS/Android)의 UX 라이팅을 자동화하기 위한 텍스트 관리 시스템입니다.

## 톤 앤 매너 원칙

### 기본 원칙
- **명확성**: 사용자가 다음에 무엇을 해야 할지 항상 명확하게 안내한다.
- **간결성**: 불필요한 단어를 제거하고 핵심 정보만 전달한다.
- **일관성**: 동일한 개념에는 항상 동일한 용어를 사용한다 (`docs/02-glossary.md` 참고).
- **친근함**: 딱딱하지 않게, 그러나 신뢰감 있는 어조를 유지한다.

### 문체 규칙
- 경어체 사용: `~하세요`, `~합니다` (명령형보다 안내형 선호)
- 부정문보다 긍정문 우선: `~할 수 없습니다` → `~이 필요합니다`
- 전문 용어는 `docs/02-glossary.md`의 표준 용어를 따른다.

## OS별 차이 처리
- iOS와 Android 용어가 다른 경우 `os` 필드로 분기한다.
- 상세 규칙은 `docs/01-os-guidelines.md`를 참고한다.

## 텍스트 구조 (strings/*.json)
각 JSON 파일은 아래 스키마를 따른다:
```json
{
  "key": "고유 식별자 (snake_case)",
  "ko": "한국어 텍스트",
  "en": "English text",
  "context": "이 텍스트가 사용되는 화면/상황 설명",
  "os": "all | ios | android",
  "type": "label | button | title | description | error | placeholder | toast"
}
```

## 폴더-화면 매핑
| 폴더 | 대상 화면 |
|------|-----------|
| 01-common | 공통 버튼, 공통 얼럿, 공통 토스트 |
| 02-auth | PIN 인증, 생체 인증, 로그인/로그아웃 |
| 03-onboarding | 초기 진입, 지갑 생성/복구, 가이드 |
| 04-home | 메인 지갑 화면, 자산 요약 |
| 05-token | 코인/토큰 목록, 상세, 시세 |
| 06-nft | NFT 목록, 상세, 컬렉션 |
| 07-more | 설정, 내 정보, 고객센터, 공지사항 |
| 08-send | 토큰/NFT 전송, 수수료 안내, 결과 |
| 09-a2a | App-to-App 서명, 연결, 권한 요청 |
