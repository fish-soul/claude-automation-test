# UX Writing Principles

사용자가 문서를 해독하게 만들지 마세요. 직관적으로 읽히고 바로 행동할 수 있도록 아래 4대 글쓰기 원칙을 준수합니다.

## 1. 능동태와 동사형 (Active & Verb-Oriented) ⭐️ 가장 중요
- 피동/수동태(~되어지다, ~당하다)와 명사형 종결을 금지합니다.
- 행동의 주체(사용자 또는 시스템)가 명확히 드러나는 능동태 동사로 작성합니다.
  - (X) "인증이 완료되었습니다." -> (O) "인증을 완료했어요."
  - (X) "오류가 발생되었습니다." -> (O) "오류가 발생했어요."
  - (X) "주소 복사 완료" -> (O) "주소를 복사했어요."

## 2. 두괄식과 간결성 (Front-loading & Concise)
- 모바일 환경에서는 앞의 2~3단어만 읽힙니다. 가장 중요한 핵심 정보(결과, 목적)를 문장 맨 앞에 배치합니다.
- 불필요한 부사(매우, 정말, 미리, 가장)와 수식어는 100% 삭제합니다.
  - (X) "안전한 서비스를 위해 미리 비밀번호를 설정해 주세요." -> (O) "비밀번호를 설정해 주세요."

## 3. 해결책 중심 (Solution-Oriented)
- 에러 상황에서 원인만 덩그러니 통보하여 사용자를 막다른 길(Dead-end)에 가두지 마세요.
- **[문제 원인] + [해결을 위한 다음 행동]** 구조를 반드시 지킵니다.
  - (X) "네트워크가 불안정합니다."
  - (O) "네트워크가 불안정해요. 와이파이 연결 상태를 확인하고 다시 시도해 주세요."

## 4. 긍정적 프레이밍 (Positive Framing)
- 시스템의 한계나 사용자의 실수를 탓하는 부정어(~할 수 없다, 잘못되었다) 대신, 어떻게 하면 원하는 것을 얻을 수 있는지 긍정문으로 전환합니다.
  - (X) "10,000원 미만은 출금할 수 없어요."
  - (O) "10,000원부터 출금할 수 있어요."
  - (X) "지갑 주소를 잘못 입력하셨습니다."
  - (O) "받는 사람의 지갑 주소를 다시 확인해 주세요."
