# OS별 용어 가이드라인

## 기본 원칙
iOS와 Android는 동일한 기능에 다른 용어를 사용하는 경우가 있습니다.
텍스트 작성 시 `os` 필드를 활용해 분기 처리하세요.

---

## 생체 인증

| 개념 | iOS | Android |
|------|-----|---------|
| 생체 인증 (통칭) | Face ID / Touch ID | 지문 인식 / 얼굴 인식 |
| 얼굴 인식 | Face ID | 얼굴 인식 |
| 지문 인식 | Touch ID | 지문 인식 |
| 인증 요청 문구 | "Face ID로 인증하세요" | "생체 인증을 사용하세요" |
| 설정 경로 안내 | 설정 > Face ID 및 암호 | 설정 > 생체 인식 및 보안 |

### 권장 처리 방식
- 특정 방식을 명시해야 할 때: OS별 분기 (`os: "ios"` / `os: "android"`)
- 통칭으로 사용할 때: "생체 인증" 사용 (`os: "all"`)

## 뒤로 가기 / 닫기

| 개념 | iOS | Android |
|------|-----|---------|
| 이전 화면으로 | 상단 좌측 `<` 또는 `취소` | 하드웨어 뒤로가기 또는 `←` |
| 모달 닫기 | 우측 상단 `✕` 또는 스와이프 다운 | 우측 상단 `✕` |

## 주의사항
- 공통으로 사용 가능한 문구는 가능하면 OS 중립적으로 작성한다.
- OS별 분기가 필요한 항목은 반드시 `os` 필드를 `"ios"` 또는 `"android"`로 명시한다.
