# Glossary (공통 용어집)

본 용어집은 프로덕트 내 텍스트의 파편화를 막기 위한 절대 기준입니다. AI는 텍스트 작성 시 'AS-IS(금지어)'가 포함되어 있다면 반드시 'TO-BE(권장어)'로 변환해야 합니다.

## 1. 자산 및 기본 명칭 (Assets & Naming)
| AS-IS (금지/지양) | TO-BE (권장) | 설명 / 사용 맥락 |
| :--- | :--- | :--- |
| 암호화폐, 가상화폐, 코인 | **가상자산** | 법적, 공식적 안내문 및 약관에서 사용 (단, UI의 좁은 버튼/탭에서는 '코인/토큰' 허용) |
| 캐시, 현금, 원화 | **원화(KRW)** | 화폐 단위를 명확히 지칭할 때 사용 |
| 어카운트, 계정 | **계정** | 로그인 및 가입 주체를 의미할 때 |
| 월렛, 내 지갑 | **지갑** | 자산을 보관하는 공간을 통칭할 때 |

## 2. 거래 및 입출금 액션 (Trading & Transfers)
| AS-IS (금지/지양) | TO-BE (권장) | 설명 / 사용 맥락 |
| :--- | :--- | :--- |
| 충전하기, 넣기 | **입금** | 외부에서 내 지갑/계정으로 자산을 가져올 때 |
| 빼기, 송금하기 | **출금** | 내 지갑/계정에서 외부로 자산을 내보낼 때 |
| 보내기 | **전송** | 블록체인 네트워크를 통해 토큰/NFT를 이동시킬 때 |
| 매입, 산다, 구매 | **매수** | 마켓에서 원화나 다른 코인으로 가상자산을 살 때 |
| 매각, 판다, 판매 | **매도** | 보유한 가상자산을 팔아 원화나 다른 코인으로 바꿀 때 |

## 3. 상태 및 결과 (Status)
| AS-IS (금지/지양) | TO-BE (권장) | 설명 / 사용 맥락 |
| :--- | :--- | :--- |
| 대기 중, 처리 중 | **진행 중** | 트랜잭션이나 주문이 아직 완료되지 않은 상태 |
| 성공, 끝남 | **완료** | 트랜잭션이나 행동이 정상적으로 끝난 상태 |
| 에러, 오류, 취소됨 | **실패** | 트랜잭션이 거절되거나 정상 처리되지 않은 상태 |
| 안 팔림, 안 사짐 | **미체결** | 매수/매도 주문이 아직 시장에서 거래되지 않은 상태 |
| 팔림, 사짐 | **체결** | 매수/매도 주문이 시장에서 거래가 완료된 상태 |

## 4. UI/UX 내비게이션 용어 (Navigation)
| AS-IS (금지/지양) | TO-BE (권장) | 설명 / 사용 맥락 |
| :--- | :--- | :--- |
| 마이페이지, 내 설정 | **내 정보** | 유저의 프로필 및 개인 설정을 관리하는 메뉴 |
| 히스토리, 기록 | **내역** | 입출금 내역, 거래 내역 등을 표기할 때 |
| 알람 | **알림** | 푸시 메시지나 서비스 내 노티피케이션 창을 지칭할 때 |
